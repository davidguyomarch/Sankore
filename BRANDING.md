# Open-Sankoré Community Edition — Branding

## Logo and visual identity

The Open-Sankoré Community Edition logo and application icon
(`resources/images/sankore-icon.png`) were created for this
community-maintained project.

They are distinct from the original Open-Sankoré branding and
third-party assets.

## Usage guidelines

The project name "Open-Sankoré Community Edition" and its logo should
not be used to imply endorsement by GIP ENA or the original Open-Sankoré
project.

## Historical assets

The `resources/` directory contains some legacy branding from the
original project (Uniboard icons, tutorial logos, etc.). These are
inherited from the original GPL-licensed source and may be replaced
in future versions.
